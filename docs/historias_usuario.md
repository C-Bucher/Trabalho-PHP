# Histórias de Usuário — Mini-SOC

Abaixo estão listadas 10 histórias de usuário que descrevem os principais fluxos funcionais do sistema **Mini-SOC**.

| ID | História de Usuário |
| :--- | :--- |
| **HU01** | **Como** analista de segurança, **quero** realizar login com e-mail e senha validados por sessão, **para** acessar o painel do Mini-SOC com segurança e proteger os registros contra acessos não autorizados. |
| **HU02** | **Como** analista de segurança, **quero** encerrar minha sessão através do botão de logout, **para** garantir que minha conta não permaneça aberta em estações compartilhadas. |
| **HU03** | **Como** administrador do SOC, **quero** cadastrar, editar e remover ativos monitorados (nome, tipo, IP e criticidade), **para** manter o inventário atualizado dos servidores e equipamentos protegidos. |
| **HU04** | **Como** analista de segurança, **quero** gerenciar categorias de ameaça (como Phishing, Força Bruta e Injeção SQL), **para** padronizar a classificação dos ataques registrados no sistema. |
| **HU05** | **Como** analista de vulnerabilidades, **quero** cadastrar CVEs associadas a ativos específicos e sua severidade, **para** rastrear quais equipamentos possuem falhas conhecidas que precisam de correção. |
| **HU06** | **Como** analista de segurança, **quero** registrar novos incidentes vinculando ativo, categoria, severidade, status e data da ocorrência, **para** documentar formalmente cada evento suspeito identificado. |
| **HU07** | **Como** analista de segurança, **quero** atualizar o status e os detalhes de um incidente existente, **para** refletir o avanço da investigação de *Aberto* até *Resolvido*. |
| **HU08** | **Como** analista de segurança, **quero** filtrar incidentes combinando texto (título ou IP do ativo), severidade, status e intervalo de datas, **para** localizar rapidamente eventos específicos durante uma investigação. |
| **HU09** | **Como** analista de resposta a incidentes, **quero** registrar ações de mitigação vinculadas a cada incidente, **para** manter um histórico auditável de todas as medidas de contenção executadas. |
| **HU10** | **Como** gestor do SOC, **quero** visualizar um relatório consolidado com totais por severidade, status e ativos mais afetados, além de exportar a listagem filtrada de incidentes em PDF, **para** acompanhar indicadores e apresentar evidências em reuniões gerenciais. |
